# Manual de Usuario: PetWorld Manager

## Introducción
Bienvenido a PetWorld Manager, esta es una aplicacion que permite la experiencia de tener una mascota virtual, dentro de la aplicación se puede interactuar con la mascota en tiempo real como crear una mascota, jugar con ella, darle de comer y conocer tu energia. Este manual explica la manera en que se puede lograr

1. Desde la terminal, ejecuta el siguiente comando para iniciar la aplicación:
   main.py


2. Aparecerá un menú principal con las siguientes opciones:

## Gestión de Mascotas
Una vez que estés en el módulo PetManager, tendrás las siguientes opciones:

1. **Cargar archivo**: Carga un archivo de configuración con la terminacion ".petworld" que contiene información sobre las mascotas existentes y las operaciones a realizar.
![Texto alternativo]()
2. **Salir**: Regresa al menú principal.

## Cómo Interactuar con las Mascotas
Una vez que hayas cargado un archivo o creado mascotas manualmente, puedes interactuar con ellas de las siguientes maneras:

- **Crear Gato**: Crea una nueva mascota gato con un nombre especificado.
- **Dar de Comer**: Alimenta a una mascota gato proporcionándole comida.
- **Jugar**: Juega con una mascota gato durante un período de tiempo especificado.
- **Resumen Mascota**: Muestra un resumen del estado actual de una mascota gato, incluyendo su nivel de energía y si está vivo o muerto.
- **Resumen Global**: Muestra un resumen global de todas las mascotas gato creadas, incluyendo sus estados y niveles de energía.

## Cómo Salir de la Aplicación
En cualquier momento, puedes seleccionar la opción "Salir" en cualquier menú para cerrar la aplicación.
